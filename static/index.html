Round trip

  1. Export here, then review / fix boxes in Label Studio.
  2. In Label Studio: Export → YOLO (zip).
  3. Back here: Datasets → Import dataset with that zip.
  4. Train → Prepare dataset to merge it in, then start training.

1 · Re-index labeled folders

Merge Label Studio exports (e.g. 1.labeled/*) into one folder with a single classes.txt (e.g. 2.re_index_label). Class ids are remapped by name; existing indices are kept and new class names are appended. Images already merged are skipped.
